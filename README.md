# 착석 (CHAKSEOK)

> 고사실 자리배치도·학생별 시험시간표 자동 생성 데스크톱 프로그램
> 2026년 업무자동화 프로그램 개발대회 출품작 — 과제번호: **교육-003**

학생 명렬표(엑셀)만 넣으면 고사실 좌석배치·개인별 시험시간표·출석부를 자동으로 만들어
한글(.hwpx)·워드(.docx)·PDF·엑셀(.xlsx)로 내보내는 **완전 오프라인** 프로그램입니다.

## 주요 기능

- **명렬표 가져오기**: xlsx/csv — 학년·반·번호·성명 열 자동 인식, 선택과목 열 자동 분류
- **교시 설정**: 공통 과목 + 선택과목(학생별 상이) 혼합 시간표
- **배치 엔진**: 번호순 / 반 섞기 / 과목 분산 / 무작위(시드 재현) + 인접 동반석 회피,
  고정 좌석(우클릭), 드래그 수동 교환, 좌석 부족·중복 학번 경고
- **문서 자동 생성**: 고사실별 좌석배치도(도면형), 학생별 시간표 카드(절취용), 고사실별 출석부
- **이름 마스킹**: 게시용 출력물에 김○연 형태로 자동 가림 — 개인정보 보호
- **보안**: 네트워크 요청 0건, 인증정보 저장 없음, 모든 처리 로컬

## 개발·빌드

```bash
pnpm install        # 의존성 설치
pnpm dev            # 웹 프리뷰 (브라우저에서도 동작)
pnpm test           # 엔진/문서생성 유닛 테스트
pnpm tauri dev      # 데스크톱 앱 개발 모드
pnpm tauri build    # 설치파일 생성 (Windows: .msi + .exe)
```

GitHub Actions(`build.yml`)에서 Windows 설치파일을 자동 빌드합니다.

## 기술 스택 및 라이선스

| 구성요소 | 용도 | 라이선스 |
|---|---|---|
| Tauri 2 | 데스크톱 앱 셸 (Rust) | MIT / Apache-2.0 |
| React 19 + Vite + Tailwind CSS 4 | UI | MIT |

| pdf-lib | PDF 문서 생성 | MIT |

| JSZip | hwpx(OWPML) 패키지 생성 | MIT |
| Pretendard | UI·PDF 한글 폰트 | SIL OFL 1.1 |
| Zustand | 상태 관리 | MIT |
| lucide-react | 아이콘 | ISC |

전 구성요소 무상 배포·사용 가능. 외부 API/서버 통신 없음.
